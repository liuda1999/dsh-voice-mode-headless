## 切换是怎么做的 / How the switch works

**CN**｜GitHub 的 README 不能跑脚本，所以用最稳的「双文件切换」：`README.md` 是中文主版，`README.en.md` 是英文版，两边顶部都放语言栏，点一下就换语言。读的时候只看到一种语言，干净利落。改内容时两份同步更新，规则写在 [CONTRIBUTING.md](CONTRIBUTING.md)。

**EN**｜GitHub READMEs cannot run scripts, so switching is done the reliable way — two files. `README.md` is the Chinese primary, `README.en.md` the English edition; both carry a language bar at the top. One click changes language, and you only ever read one language at a time. Both editions are kept in sync; see [CONTRIBUTING.md](CONTRIBUTING.md).
